Courier Tracking System

This is a simple Python program for a courier tracking system. It helps to book parcels, update their delivery status, and track them using a tracking ID.

What it does
- Books a new parcel and gives a tracking ID (like CT1001).
- Updates parcel status step by step (Booked -> Picked Up -> In Transit -> Out for Delivery -> Delivered).
- Tracks the parcel and shows its full status history.

 How to run
1. Make sure Python 3 is installed.
2. Run the file in terminal or command prompt:
   python one.py
